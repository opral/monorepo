`inlang check --unused-messages` supports next-intl projects with `@inlang/plugin-next-intl` 2.4.0 or later. With an older next-intl plugin, it asks to update the plugin's module URL instead of suggesting the Paraglide matcher, and the note under incomplete results no longer only shows a Paraglide example.
